В ответ на запрос на нажатие кнопки в панели Networks браузера можно увидеть ошибку 403 для неподходящего пользователя
или коллекцию случайных объектов для подходящего. 


Keycloak поддерживает PKCE по умолчанию для всех клиентов OAuth 2.0, так что дополнительных действий в Keycloak по настройке PKCE обычно не требуется.
Spring Boot автоматически поддерживает PKCE для authorization_code гранта, если клиент настроен правильно.
Для использования PKCE в Spring Boot не требуется дополнительных действий.
